# SpeedyIndex MCP

An unofficial Model Context Protocol (MCP) server project for SpeedyIndex SEO workflows.

The foundation is in development. No MCP tools, application runtime, installable package, or runnable quickstart are implemented yet. This project is independently maintained and is not affiliated with or endorsed by SpeedyIndex.

The roadmap proposes 12 tools, starting with the read-only `get_balance` tool. Task inspection, submissions, checks, retry planning, report comparison, and campaign summaries are later work; none are available today. See the [implementation plan](docs/implementation-plan.md) for the full list and delivery gates.

Contributor guidance is in [AGENTS.md](AGENTS.md). Framework attribution and source revisions are recorded in [provenance](docs/provenance.md).
